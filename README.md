VitalCheck

A browser-based BMI and health prediction tool built for India. 

# Features

- BMI calculator with Asian population cutoffs
- Lifestyle survey (sleep, smoking, diet, activity, stress)
- Adaptive medical history survey (branching questions based on your answers)
- Health score with personalised recommendations
- Nearby hospital finder using geolocation
- AI health chatbot powered by Claude

# Deployment

Currently hosted temporarily on **Amazon Web Services (AWS EC2)**. (Closed)

#Stack

Vanilla HTML/CSS/JS · Gemini API for chatbot · AWS EC2 · Browser Geolocation · Google Fonts

# Disclaimer

This tool is for general awareness only. It is **not a medical diagnosis**. Always consult a qualified doctor. For emergencies call **112**.
